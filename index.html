Cloud Computing La computación en la nube

Es la entrega de servicios informáticos (servidores, almacenamiento, bases de datos, redes y software) a través de Internet. En lugar de comprar y mantener equipos propios, se alquilan los recursos y se paga solo por lo que se usa.

Ejemplos: AWS, Microsoft Azure, Google Cloud

SaaS Software como servicio

El proveedor entrega una aplicación lista para usar desde el navegador y se encarga de todo lo demás. El usuario solo la utiliza, sin instalar nada.

Ejemplos: Gmail, Microsoft 365, Google Docs

PaaS Plataforma como servicio

Ofrece un entorno listo para crear, probar y publicar aplicaciones sin administrar servidores ni sistemas operativos. El programador se enfoca solo en su código.

Ejemplos: Google App Engine, Heroku, Azure App Service

IaaS Infraestructura como servicio

Entrega recursos básicos bajo demanda: máquinas virtuales, almacenamiento y redes. El usuario administra el sistema operativo y las aplicaciones.

Ejemplos: Amazon EC2, Azure Virtual Machines, Google Compute Engine

Virtualización Varios equipos en uno

Permite ejecutar varios sistemas operativos o servidores virtuales sobre un mismo equipo físico, gracias a un programa llamado hipervisor. Así se aprovechan mejor los recursos y se ahorran costos.

Ejemplos: VMware, VirtualBox, Hyper-V

Docker Contenedores

Docker empaqueta una aplicación con todo lo que necesita (código, librerías y configuración) en un contenedor. Es más ligero que una máquina virtual porque comparte el sistema operativo, y funciona igual en cualquier equipo.

Comandos clave: docker build, docker run
